# 청년부 주보

청년부 주보 제작 UI는 보류 상태다. 예배 진행용 Presenter가 우선이며,
주보 전용 화면/편집 기능은 별도 DB 구조와 UI가 준비될 때 다시 연다.

## 현재 데이터 원칙

- 예배 순서는 `mindex_worship_elements`의 현재 청년부 예배 항목에서 만든다.
- 대표기도자는 같은 날짜의 `mindex_sunday_calendar.young_adult_prayer`를 우선 사용한다.
- 교회력 값이 아직 없을 때만 현재 예배의 대표기도 항목 담당자를 표시한다.
- 주보 기능을 다시 열기 전까지 별도 주보 데이터를 `notes`나
  `source_ref`에 임의 저장하지 않는다.

## 재개 시 동기화 계약

대표기도자는 교회력이 canonical source다. 주보 기능을 재개할 때
Presenter/예배 편집에서 대표기도자를 바꾸면 교회력도 함께 갱신하는
write path를 Data 영역에서 `young_adult_prayer` 한 곳으로 구현한다. 그
작업이 완료되기 전까지 주보는 교회력 값을 우선 표시해 값이 갈라지지
않게 한다.

## 다음 데이터 범위

IDML 양면 템플릿의 주보 전용 항목은 아래처럼 별도 구조로 추가한다.

- 호수와 발행일
- 청년부 소식
- 교회 일정
- 임원 및 섬김이 명단
- 설교 노트의 보조 문구

이 항목들은 예배 순서와 성격이 달라 Presenter 슬라이드 메모에 저장하지 않는다. DB 구조가 준비되면 같은 주보 화면에서 편집하도록 확장한다.
